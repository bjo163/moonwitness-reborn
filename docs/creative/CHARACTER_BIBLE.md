# Character Bible and Identity Boundaries

**Status: boundary specification, not a canon bible.** The audited source set is incomplete; no new character facts are introduced here.

## Canonical distinction

- Real/historical person → `ql_person`.
- Fictional character and universe canon → `ql_character`.
- Executable model/tool configuration → `ql_ai`.
- User account → `ql_auth`.
- Story/narrative work → `ql_story`.
- Historical event → `ql_event`.

These identities must not be merged because a story depicts a person, a character has an AI interface, or an agent uses a persona. Fictional characters are never represented as prophets, angels or historical fact. AI persona copy does not grant authority to the system.

## Canon record requirements before publication

Character ID and name variants; fictional status; universe; approved appearance/voice references; creator and source; canon status/version; relationships/arcs with source; cultural/religious sensitivity review; asset/license record; allowed use and editorial owner. Mark speculative or noncanonical material explicitly.

## Audit disposition

Story/witness repositories, ROCKSOUL domains and assets are candidate knowledge/design sources. Their full character records and asset rights were not audited. Preserve originals and IDs. Import only mapped, attributed, licensed content; otherwise reference privately for review. Do not generate missing canon from model inference.
