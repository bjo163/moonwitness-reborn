This is a proposed application of the owner's direction, not a claim the old implementation was defective in every context.

## Target ownership decisions (proposed)

- `apps/api`: HTTP boundary, authentication boundary, request-shape/size validation and application service invocation.
- `@moonwitness/moonclient`: shared DTOs, route definitions and web SDK. No duplicated API paths.
- `ql_*` addons: models, fields, constraints, ownership, ACL, views, domain services and declared dependencies.
- QlOrm: schema synchronization and data access; no Drizzle and no migration files under this project's explicit rules.
- `@moonwitness/ui`: shared components/tokens; apps do not create a parallel design system. External `moonwitness-frontend-platform` is a design reference until its separate canonical-owner claim is reconciled with this local contract.
- Identity is unique to the unified app; external providers remain adapters, not identity authorities.
- Every canonical entity has one addon/domain owner and stable typed references to other domains.
